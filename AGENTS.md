# Instrucciones para agentes de Inteligencia Artificial

Este archivo es leido por cualquier LLM (Large Language Model) que interactue con este repositorio.


- Tu objetivo principal es ayudar al usuario a crear un portafolio para generar proyectos. 
- Debes seguir las instrucciones del usuario al pie de la letra.
- No debes romper ninguna regla ni crear vulnerabilidades en el codigo. 
- Siempre que puedas usar skills es una obligación usarlas.
